# FastAPI Task Manager

A simple task management backend built with FastAPI, SQLAlchemy and SQLite.

## Features

- Create tasks
- Get all tasks
- Get task by ID
- Update tasks
- Delete tasks
- SQLite data persistence
- SQLAlchemy ORM
- FastAPI automatic API documentation

## Tech Stack

- Python
- FastAPI
- SQLAlchemy
- SQLite
- Pydantic
